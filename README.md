# 🎁 Forever Gifts — Online Gift Shop

A fully responsive gift shop website built with HTML, CSS, and Bootstrap.
Designed to feel like a real e-commerce store for gifts and special occasions.

## 🔗 Links
- 🌐 Live Site: [forevergiftshop.netlify.app](https://forevergiftshop.netlify.app)
- 💻 GitHub Repo: [github.com/anusiya-dev/forever-giftshop](https://github.com/anusiya-dev/forever-giftshop)

## 📸 About the Project
Forever Gifts is a frontend e-commerce project for an online gift shop
based in Tirunelveli, TamilNadu. It features product listings with
categories, a cart, checkout, testimonials, and a multi-page layout —
all styled to look like a real business website.

## ✨ Features
- Responsive navbar with cart count
- Hero section with image carousel (Gifts & Chocolates)
- Product grid with category filter tabs (All, Chocolates, Teddy Bears, Flowers, Cute Gifts)
- Most Loved Gifts section
- Stats section (1963 customers, 99% satisfaction, 33 categories)
- Customer testimonials
- Newsletter subscription
- Multi-column footer with contact info and payment icons
- Shop, Shop Detail, Cart, Checkout, and Contact pages

## 🛠️ Built With
- HTML5
- CSS3
- Bootstrap 5

## 📁 Pages
- `index.html` — Homepage
- `shop.html` — All products
- `shop-detail.html` — Single product detail
- `cart.html` — Shopping cart
- `checkout.html` — Checkout page
- `contact.html` — Contact form

## 🚀 Getting Started
1. Clone the repo
   git clone https://github.com/anusiya-dev/forevergift-shop.git

2. Open `index.html` in your browser — no setup needed.
